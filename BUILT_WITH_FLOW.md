# Built with Wispr Flow

Boli-Quote was built **hands-free**: specs, prompts, code instructions and docs were dictated with [Wispr Flow](https://wisprflow.ai) into the editor and AI coding tools. This file is submission evidence for the Scaler × Wispr Flow "India Runs on Voice" hackathon.

> Wispr Flow is our **development tool**. It is *not* the speech engine inside the app (the app uses an Indic STT — see [docs/TECH_STACK.md](docs/TECH_STACK.md)).
